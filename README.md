<h1>Parapet</h1>

</div>
A Rust static site auditor. It catches broken links, dead anchors, stale sitemaps and CSP hash drift in your build output, with no browser involved.

## Overview

Parapet is a command-line tool written in Rust for teams that ship static sites. It reads the built output directory (for example `dist/`), resolves every reference in memory, and fails the build if anything doesn't line up. It needs no server and no network, gives the same verdict for the same files, and points to the exact file and reference that failed.

## Features

Link and Anchor Verification

- Two-pass DOM check: every `id` and `<a name>` is indexed first, then every `#fragment` is resolved against its target page.
- Covers `<a href>`, `<link href>`, `<script src>` and `<img src>`.
- Resolves direct files, directory indexes (`/services` to `services/index.html`) and `.html` fallbacks.
- Applies rewrite and redirect rules from `vercel.json` and `_redirects` before checking a target.

Content Security Policy Audit

- Extracts executable inline scripts and ignores non-executable types such as `application/ld+json` and `importmap`.
- Computes SHA-256 digests in CSP format (`sha256-<base64>`).
- Confirms each hash is declared in your deploy manifests: `public/_headers`, `vercel.json`, `netlify.toml`.

Sitemap and Feed Validation

- Checks every `<loc>` in `sitemap.xml` against real generated routes.
- Checks every URL in `llms.txt`, so crawlers and AI agents never hit a dead route.
- Detects the canonical domain automatically from `sitemap.xml`.

CI Behavior

- Exits `1` on any integrity error and `0` when clean.
- `--warn-only` mode reports problems without failing the build.
- Individual checks can be skipped with `--skip-csp`, `--skip-sitemap` and `--skip-llms`.

## Pipeline

```text
vite build + prerender  ->  dist/  ->  parapet  ->  deploy (or exit 1)
```

Parapet runs right after the build and reads only the output directory. A failing run stops the pipeline before anything is deployed.

## Performance

Measured on a production static site with 17 prerendered pages and 272 links and assets:

| Metric | Parapet | Playwright / Cypress | Node regex script |
| :--- | :--- | :--- | :--- |
| Execution time | 28 ms | 30 to 60 s | ~1.8 s |
| Memory | < 12 MB | 400 to 800 MB | ~150 MB |
| CSP hash audit | Built in | Custom tooling | Custom script |

Results vary with site size and hardware.

## Quick Start

### Prerequisites

Rust toolchain (stable, 2021 edition or newer). Install from [rustup.rs](https://rustup.rs).

### Option 1: Install with Cargo

```bash
cargo install parapet
parapet dist
```

### Option 2: Build from Source

```bash
git clone https://github.com/nirjxr26/parapet.git
cd parapet
cargo build --release
./target/release/parapet dist
```

### Usage

```bash
# Set the canonical domain explicitly
parapet dist --domain https://example.com

# Report problems without failing the build
parapet dist --warn-only

# Skip individual checks
parapet dist --skip-csp --skip-sitemap
```

| Option | Description |
| :--- | :--- |
| `-d, --domain <DOMAIN>` | Canonical domain. Default: detected from `sitemap.xml` |
| `-m, --manifests <FILES>` | Manifests to check. Default: `public/_headers`, `vercel.json`, `netlify.toml` |
| `-r, --root <ROOT>` | Project root. Default: auto-detected |
| `--skip-csp` | Skip the inline script hash audit |
| `--skip-sitemap` | Skip `sitemap.xml` validation |
| `--skip-llms` | Skip `llms.txt` validation |
| `--warn-only` | Always exit with code 0 |
| `-q, --quiet` | Suppress non-error output |

### Example Output

```text
Broken anchor in 'dist/sitemap/index.html':
  '/services#cloud-architecture' has no element with id='cloud-architecture'

Security manifest drift:
  vercel.json is missing inline script hash 'sha256-...'
```

## CI Integration

GitHub Actions:

```yaml
- name: Build
  run: npm ci && npm run build

- name: Verify
  run: |
    cargo install parapet
    parapet dist
```

npm scripts:

```json
{
  "scripts": {
    "verify:site": "parapet dist",
    "test": "npm run build && npm run verify:site"
  }
}
```

## Limitations

- Only static output is analysed. Ids and links generated by JavaScript at runtime are not visible to Parapet.
- External URLs are not requested, so links to other sites are not checked.
- HTML is scanned with pattern matching, so unusual markup may be missed.
